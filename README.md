# MovArch

A website where a user can search a database of movies, TV shows, and filter the results.

## Technologies
- React
- Axios
- FontAwesome

## Features
- Simple interface for searching movies and filtering results

## Future Improvements
- Provie boiler plate movie poster where API doesn't provide an image.

## Author
Developed by Broady Butler

## Getting Started

This project was bootstrapped with [Create React App](https://github.com/facebook/create-react-app).

1. Clone Repository

```bash
- git clone https://github.com/broadaciousb/movieReactSite
```

2. Install Dependencies

```bash
- npm install
```

3. Run Development Server

```bash
- npm start
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
